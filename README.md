# Оно тебе надо

Страница аукциона вещей, в которые когда-то никто не верил. Проектная работа по вёрстке для Яндекс Практикума.

## Стек

HTML5, CSS3. Страница собрана без сборщика и открывается напрямую через `index.html`.

## Структура

- `index.html` — семантическая разметка;
- `styles/global.css` — общие стили из шаблона;
- `styles/style.css` — стили страницы;
- `fonts/`, `images/` — шрифты и изображения из шаблона.
